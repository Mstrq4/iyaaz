# IYAAZ Brand Assets

The canonical production logo is `public/brand/iyaaz-logo.svg`.

Brand requirements:
- Preserve the approved IYAAZ ribbon geometry and clear central negative space.
- Use Deep Amethyst `#3E1848` and Whisper Lavender `#E7E6F5` as the core palette.
- SVG assets must remain responsive and contain a `viewBox`.
- UI icons use `currentColor` so Light/Dark themes control icon color.
- Do not raster-trace the mark or introduce polygonal nicks, holes, or broken overlaps.
