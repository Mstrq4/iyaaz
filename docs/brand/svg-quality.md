# SVG Quality Contract

IYAAZ production identity assets are authored as native SVG rather than raster traces.

Acceptance checks:
- smooth continuous ribbon silhouettes;
- no polygonal nicks, accidental gaps, clipping holes, or broken overlaps;
- responsive `viewBox` sizing;
- accessible title/description where the SVG is standalone;
- gradients/filters declared in `<defs>`;
- themeable UI icons use `currentColor`;
- Light/Dark variants preserve contrast;
- directional UI icons flip only where direction semantics require it.

The approved brand board remains the visual reference for proportions, depth, glass highlights, and the amethyst/lavender material treatment.
